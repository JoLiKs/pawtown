# Хвостоград (Pawtown) v0.1 — уютная игра про жизнь питомца для Roblox

▶ **Веб-демо (настоящий Luau-код в браузере):** https://joliks.github.io/pawtown/
· Концепт и роадмап: [`docs/DESIGN.md`](docs/DESIGN.md)

Подросток из Люмен-Хиллс в ночь Звездопада превращается в питомца из приюта «Тёплый нос». Выберите тело — кошку,
собаку, кролика или попугая (у каждого свои способности), обживитесь в новой семье, учите трюки в ритм-игре,
дружите с другими питомцами и собирайте осколки памяти, пока за вами наблюдает загадочный Полуночный кот.

![Выбор вида](docs/screens/02_species_choice.png)

## Что есть в v0.1

* **4 вида со способностями:** кошка (двойной прыжок, бег по крышам), собака (нюх, копание, «лучший друг»),
  кролик (рывок, подкоп под забором), попугай (взмахи в воздухе, планирование, пародия). Редкие и легендарные
  виды — модель данных и окно «Звёздная ночь — скоро» с требованиями.
* **Потребности и настроение** (сытость, энергия, чистота, веселье, любовь) — мягкие, офлайн не ниже 40 %.
* **Действия:** еда и вода, сон (ночь проматывается, если спят все), ванна-мини-игра, игрушки, апорт,
  аджилити-трасса на время, ласка и выпрашивание у семьи.
* **Трюки:** ритм-игра с медалями (5 трюков, открываются по уровню), оценка на сервере.
* **Семья** (папа, бабушка, Мия) со шкалами привязанности; **уровни, возраст** (малыш → подросток → взрослый),
  **таланты** (3 ветки × 2), **репутация** улицы и парка, **эмоции** и **дружба** питомцев.
* **Мир:** приют, дом, Кленовая улица с домами соседей и тайным садом, парк «Одуванчик», день и ночь.
* **Сюжет:** глава 1 «Новый дом» (7 шагов, заставки «Удочерение» и «Сон») + 5 ежедневных заданий из 8.
* **Экономика:** лакомства за игру и бутик косметики (ошейники, банданы, шапки). **Robux нет.**
* **Интерфейс:** компактный HUD для ПК и телефонов (кнопки ≥ 36 px, текст ≥ 12 px), значки из примитивов GUI,
  русский и английский язык с автоопределением.
* **Бэкенд:** сервер авторитарен (один RemoteFunction `Action` + Router), античит скорости и телепортов,
  DataService с сессионной блокировкой и миграциями.

## Как опубликовать в Roblox — пошагово

1. **Установите Roblox Studio** (https://create.roblox.com) и войдите в аккаунт.
2. **Откройте место.** Скачайте `Pawtown_v0.1.rbxl` (или `.rbxlx`) из [релиза v0.1](https://github.com/JoLiKs/pawtown/releases)
   либо соберите сами (см. «Сборка»). Двойной щелчок по файлу откроет его в Studio.
3. **Проверьте в Studio:** кнопка **Play** (F5). Вы появитесь в приюте; подойдите к светящейся стойке и нажмите E,
   чтобы выбрать вид. Для теста на телефоне — **Test → Device** (iPhone, 844×390 и т. п.).
4. **Опубликуйте:** **File → Publish to Roblox As…** → *Create new game* → название «Хвостоград / Pawtown»,
   описание (можно взять первый абзац этого README), жанр *Town and City*. Нажмите **Create**.
5. **Включите сохранения:** **Home → Game Settings → Security → Enable Studio Access to API Services** (для тестов
   сохранений в Studio). В опубликованной игре DataStore работает и без этого.
6. **Анкета возрастного рейтинга (Experience Questionnaire)** на https://create.roblox.com → ваша игра →
   *Audience → Questionnaire*: насилия нет, общение — стандартный чат Roblox, покупок нет.
7. **Страница игры:** иконка 512×512 и миниатюры 1920×1080 (можно сделать из `docs/screens/`), описание на двух языках,
   *Localization → включите Russian* (тексты игры уже переведены внутри скриптов).
8. **Поддерживаемые устройства:** *Places → Configure → Devices*: Computer, Phone, Tablet.
9. **Откройте игру:** *Settings → Privacy → Public*. Готово.

Монетизации в v0.1 нет. Если позже добавите платные предметы — только косметика, у случайных наборов указывайте
шансы, никаких бонусов в соревнованиях (правила Roblox и принципы игры, см. `docs/DESIGN.md` §6).

## Сборка

Нужны: Python 3, (по желанию) Rojo 7. Бинарники инструментов скачиваются в `tools_dl/` (не в репозитории).

```bash
python3 tools/build_rbxlx.py                      # build/Pawtown.rbxlx без Rojo
rojo build default.project.json -o Pawtown.rbxl   # бинарный .rbxl через Rojo
rojo serve                                        # живая синхронизация со Studio (плагин Rojo)
```

## Проверки

```bash
bash tools/check_all.sh            # StyLua, Selene, строки локализации, luau-lsp (strict), юнит-тесты,
                                   # интеграционный сценарий в эмуляторе roblox2web, сборка и валидация .rbxlx
UI_TEST=1 bash tools/check_all.sh  # + браузерный тест интерфейса (Chromium) со скриншотами в docs/screens
```

* `tests/cases.lua` — более 1000 юнит-проверок логики (потребности, прогресс, трюки, задания, перерождение,
  экономика, миграции, блокировка сессий DataService, паритет локализаций, отсутствие эмодзи, раскладки).
* `tests/game/` — полный сценарий главы 1 и способности всех видов в эмуляторе (78 проверок).
* `tests/browser/test_game_ui.py` — клики по настоящему интерфейсу на 1280×720, 390×844 и 844×390.

## Веб-демо

`bash tools/publish_web.sh /workspace/pawtown-web` — собирает веб-версию транспилятором
[roblox2web](https://github.com/JoLiKs/roblox2web) и кладёт её в ветку `gh-pages` (GitHub Pages).
Эмулятор не воспроизводит звук и упрощает физику; в веб-демо день короче (5 минут).

```

src/ReplicatedStorage    общие данные и логика (виды, трюки, задания, магазин, локализация, мир)
src/ServerScriptService  сервисы: Router, DataService, Needs, Family, Trick, Ability, Park, Quest, Shop, Social, AntiExploit…
src/StarterGui           интерфейс (HUD, окна, мини-игры, заставки)
src/StarterPlayer        анимация питомца, локализация подписей мира
tools/                   сборка, проверки, генератор локализаций (tools/locale)
tests/                   юнит-, интеграционные и браузерные тесты
docs/                    концепт (DESIGN.md) и скриншоты
```
